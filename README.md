## 🌐 Sobre este repositorio

Este repositorio reúne proyectos que he construido durante mi **especialización en Ciencia de Datos e Inteligencia Artificial**. Cada carpeta representa una etapa de aprendizaje aplicada: desde la exploración y visualización de datos hasta el entrenamiento, evaluación y puesta en práctica de modelos de Machine Learning.

Más que una colección de notebooks, este espacio funciona como un **portafolio vivo** de experimentación, análisis y aprendizaje continuo. Aquí documento procesos, pruebo hipótesis y transformo conjuntos de datos en historias que pueden ser entendidas y utilizadas.

## 🧠 Proyecto destacado: riesgo de depresión

El proyecto [`riesgo-de-depresion`](./riesgo-de-depresion) estudia patrones relacionados con el uso de redes sociales, el sueño, la actividad física, el estrés, la ansiedad y el rendimiento académico. Su objetivo es explorar cómo estas variables pueden contribuir a clasificar distintos niveles de riesgo de depresión mediante modelos predictivos.

> Este análisis es un ejercicio académico de Ciencia de Datos. **No constituye una herramienta de diagnóstico médico ni reemplaza la evaluación de profesionales de la salud.**

## 🚀 Ruta de aprendizaje

La organización de este repositorio sigue una ruta práctica:

1. **Comprender los datos**, sus variables, calidad y contexto.
2. **Explorar patrones** mediante estadística descriptiva y visualizaciones.
3. **Preparar la información** para que pueda ser utilizada por algoritmos de Machine Learning.
4. **Entrenar y comparar modelos** usando métricas apropiadas para cada problema.
5. **Comunicar resultados** de forma clara, reproducible y responsable.
